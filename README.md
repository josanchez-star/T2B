# T2B
A tech assignment for i.c.stars Cycle 60, focused on learning Git and GitHub.
About
This repository was created as part of a hands-on GitHub assignment from the i.c.stars Cycle 60 program. The goal is to practice the core version control workflow: creating a repository, editing files, writing commits, and documenting work with a README.
Assignment Details
Program: i.c.stars
Cohort: Cycle 60
Instructors: Marc and JV
Author: John S. (@josanchez-star)
What I Practiced
Creating a new GitHub repository
Editing files directly on GitHub
Writing clear commit messages
Using Markdown to format a README
Getting Started
To get a copy of this repository on your computer:

git clone https://github.com/josanchez-star/T2B.git
cd T2B
